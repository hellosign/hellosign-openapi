# # SubEditorPageOptions

Controls which completed pages are shown again when the embedded Fax draft is opened.

## Properties

Name | Type | Description | Notes
------------ | ------------- | ------------- | -------------
| `force_upload_page` | ```bool``` |  When set to `true`, always shows the upload page, even when files are already attached. Defaults to `false`.  |  [default to false] |
| `force_editor_page` | ```bool``` |  When set to `true`, always shows the editor page, even when the document is already prepared. Defaults to `false`.  |  [default to false] |
| `force_review_page` | ```bool``` |  When set to `true`, always shows the review page, even when recipients and Fax details are already provided. Defaults to `false`.  |  [default to false] |
