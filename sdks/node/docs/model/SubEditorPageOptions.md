# # SubEditorPageOptions

For embedded Fax drafts only. Controls which completed pages are shown again when the draft is opened.

## Properties

Name | Type | Description | Notes
------------ | ------------- | ------------- | -------------
| `forceUploadPage` | ```boolean``` |  When set to `true`, always shows the upload page, even when files are already attached. Defaults to `false`.  |  [default to false] |
| `forceEditorPage` | ```boolean``` |  When set to `true`, always shows the editor page, even when the document is already prepared. Defaults to `false`.  |  [default to false] |
| `forceReviewPage` | ```boolean``` |  When set to `true`, always shows the review page, even when recipients and Fax details are already provided. Defaults to `false`.  |  [default to false] |
