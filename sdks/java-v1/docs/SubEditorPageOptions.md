

# SubEditorPageOptions

For embedded Fax drafts only. Controls which completed pages are shown again when the draft is opened.

## Properties

| Name | Type | Description | Notes |
|------------ | ------------- | ------------- | -------------|
| `forceUploadPage` | ```Boolean``` |  When set to `true`, always shows the upload page, even when files are already attached. Defaults to `false`.  |  |
| `forceEditorPage` | ```Boolean``` |  When set to `true`, always shows the editor page, even when the document is already prepared. Defaults to `false`.  |  |
| `forceReviewPage` | ```Boolean``` |  When set to `true`, always shows the review page, even when recipients and Fax details are already provided. Defaults to `false`.  |  |
